# Portfolio Project Summary

## Project Title

AI-Powered Tax Operations Intelligence &
SLA Prevention Engine

## One-Sentence Description

Built a local Python-based tax operations prototype
combining SLA prioritisation, case lifecycle management,
explainable recommendations, and AI-assisted case analysis.

## Technical Stack

Python | Streamlit | SQLite | pandas |
Ollama qwen3:8b | unittest

## Demonstrated Features

- Business-hour and calendar-hour SLA modeling
- Operational priority queue
- Context-aware follow-up recommendations
- Case intake and status audit history
- Local AI-assisted classification
- AI freshness checks using input fingerprints
- Synthetic evaluation and automated validation

## Evidence

- 50-case synthetic simulation
- 2 breached, 5 at risk, 43 within SLA
  under the modeled business-hours policy
- Automated priority queue validation
- Eight passing isolated integration tests
- Seven reported passing manual checks

## Important Qualification

The project does not demonstrate a measured reduction
in real-world SLA breaches, production deployment,
or regulatory compliance.

## Resume Bullet

Developed a Python, Streamlit, and SQLite-based
tax operations prototype integrating deterministic
SLA prioritisation, context-aware recommendations,
local Ollama case analysis, audit logging, and
AI freshness checks; validated workflows using
synthetic cases and automated tests.

## Suggested Interview Positioning

Focus on the system design decisions, testing,
data quality limitations, and operational value
of separating deterministic rules from AI output.
